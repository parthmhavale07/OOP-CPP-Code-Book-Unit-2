## 💻 Programs

This repository contains **16 practical programs** based on Inheritance concepts in C++. The programs cover different types of inheritance, constructors and destructors, function overriding, abstract classes, virtual base classes, friend classes, nested classes, and real-world applications.

### 01. Basic Single Inheritance

Demonstrates single inheritance using `Person` as a base class and `Student` as a derived class.

### 02. Protected Member Access

Demonstrates how a derived class can access a protected member of the base class.

### 03. Public versus Private Inheritance

Demonstrates the effect of public and private inheritance on member accessibility.

### 04. Multilevel Inheritance

Demonstrates a three-level inheritance hierarchy using `Person → Employee → Manager`.

### 05. Hierarchical Inheritance

Demonstrates hierarchical inheritance using `Vehicle` as a common base class for `Car` and `Bike`.

### 06. Multiple Inheritance

Demonstrates multiple inheritance using `Academic` and `Sports` as base classes.

### 07. Multiple-Inheritance Ambiguity

Demonstrates how to resolve ambiguity between base-class functions using the scope-resolution operator.

### 08. Constructor and Destructor Order

Demonstrates the order of constructor and destructor execution in inheritance.

### 09. Parameterized Base Constructor

Demonstrates how a derived-class constructor initializes a parameterized base class.

### 10. Function Overriding

Demonstrates function overriding using `virtual` and `override` keywords.

### 11. Abstract Class

Demonstrates the use of an abstract base class with a pure virtual function.

### 12. Virtual Base Class and Diamond Inheritance

Demonstrates how a virtual base class solves duplicate-base ambiguity in diamond inheritance.

### 13. Friend Class

Demonstrates how a friend class can access private data of another class.

### 14. Nested Class

Demonstrates the creation and use of a class defined inside another class.

### 15. Vehicle Rental System

Demonstrates an inheritance-based vehicle rental application using `Vehicle`, `Car`, and `Bike` classes.

### 16. Employee Payroll System

Demonstrates an employee salary system using an abstract base class, inheritance, and function overriding.
